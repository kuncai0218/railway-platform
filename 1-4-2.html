1.4.2 变化检测标注规范

变化检测标注回答“哪里变了”。三个测点的 Sentinel-2 已经用逐期判读系统开展：每一期先判断能不能看清，再和上一期比较、画框标出变化，组长确认后再逐格精确标注。最后按统一规则生成 0 / 1 / 255 的正式标签。

逐期判读的三步

  1. 第一步：这一期看得清吗四档：清楚 / 整体模糊但还能看 / 有些地方看不清 / 基本看不清。看不清的地方画框；原因多选（云、雾霾、阴影、黑块缺失、条纹、太亮太暗、模糊）并可自填。
  2. 第二步：和上一期比左右两图同步缩放拖动。先勾“不同点”（没有明显不同、地面有局部变化、整体颜色或亮度、清晰程度、整体错位、云或云影位置、山的阴影、植被整体变绿变黄、水的颜色）；地面某处变了就画框，并选变化类别（可多选）。
  3. 组长确认第二步确认 / 修改后确认 / 不是变化 / 只加批注。有局部变化的期确认后开放第三步。
  4. 第三步：精确标注在确认过的框里逐格（10 m）涂“变化”“拿不准”，不能改框；一个格子一多半变了才涂“变化”。
  5. 组长检查第三步通过或退回（退回必须写明原因）。

变化类别：裸土 / 施工 增加、减少；建筑 增加、减少；道路 增加、减少；植被 增加、减少；水面 扩大、缩小；有差别但说不清是什么。整体性的差别（颜色、亮度、清晰程度、错位、云影、季节、水色）只在“不同点”里勾选，不画框。

工作台三测点逐期判读系统株洲南、衡阳北、韶关南 2021—2026 年全部 505 期；学习、判读、实时看板、组长台打开 ›

编码与正式标签

每一对影像生成一张 256 × 256 的标签：1 变化、0 经核查的稳定区域、255 未审查或不可判读。生成规则：

  1. 未审查、不可判读和观察范围外先记255；经核查的稳定区域才记0。
  2. 采用清楚前图与框级指定前图，页面、AI预标和导出保持一致。跳过中间期时，中间已发生变化的范围不自动记稳定。
  3. 已保存且前图匹配的组长精标优先；其余框采用AI精标，红1、黄255、框内已核查的其余格0。旧“仅人工保存框可训练”规则已被后续决定替代。
  4. 云、云影、缺测及前后配准无效范围保持255；换观察范围后尚未复看的新增区域和框外待核候选也保持255。
  5. 前图更改后，旧人工标签不直接沿用；需按新前图重看、重存。AI来源与人工来源分别记录。

同时输出变化对象清单（位置、类别、格子数）和事件过程编号（同一处跨多期的变化归为一组，防止训练集和测试集泄漏）。组长台可以导出“正式标注数据（JSON）”，由脚本转成 GeoTIFF。

已统一的判读规则与剩余人工核查

  • 水面反光：纯反光只记观测差异，不画地面变化框；反光期中确有涨落、收割或施工时，结合清楚影像核实并保留真实变化，不因“有反光”一律删除。
  • 水位涨落：水库、池塘随降雨涨落是真实变化，应标“水面 扩大 / 缩小”；只是水色变浑或变清，只勾“水的颜色变了”。
  • 云影：上一期的云影会让林地看起来像裸土，应在第一步圈为“看不清”，不画变化框。

复核入口与已完成动作（2026-10-06）

改框、改类别、换前图、补漏在AI复核台操作；逐格修改变化/拿不准在变化精标台操作。第四轮框级动作与新右岸范围补框已经处理，e版标签已用于训练；“已做过”与“需要组长再看”分开显示。

AI多轮核查不等于独立人类验收；未保存或拿不准的范围不能写成全部人工确认。
